## AI Use

I used Claude to reorganise my automation project descriptions into a more direct format 
and to hack a fork of the Confluence XML to markdown converter (https://github.com/oberlies/confluence-to-markdown-converter) into shape to recover old Abiquo wiki files.

For the diagrams, I used Claude to generate a text diagram to use instead of a PNG version of a Mermaid file, and I got ChatGPT to convert a sequence diagram file in PNG format to Mermaid.
